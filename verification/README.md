# Release verification

The relocated release project was checked on **2026-09-13** with
Lean 4.28.0 and the pinned mathlib commit. **All nine gates passed**.
All **361 mathematical modules were freshly compiled**; no project module
was reused. The pinned external dependency cache was reused.

The mathematical modules, root imports, original manuscript, and pinned
build configuration are byte-identical to the audited source project.
This release reorganizes the audit entry points and documentation and
makes the verification scripts portable.

| Evidence | Contents |
|---|---|
| [release-check.json](release-check.json) | Gate results, environment, source and audit hashes, and scope |
| [source-build.json](source-build.json) | Compilation status and source/dependency/object hashes for every mathematical module |
| [main-dependencies.json](main-dependencies.json) | Actual main-theorem proof-expression dependency paths |
| [explicit-dependencies.json](explicit-dependencies.json) | Actual explicit-theorem proof-expression dependency paths |
| [logs/](logs/) | Output from each of the nine gates |
| [release-manifest.json](../release-manifest.json) | SHA-256 of every distributed file except the manifest itself |

The axiom audit inspected 5074 project declarations.
Only `propext`, `Classical.choice`, and `Quot.sound` occurred; the explicit
mathematical premises remain as documented in [ASSUMPTIONS.md](../docs/ASSUMPTIONS.md).
The main and explicit route checks found all 130 and
171 required proof checkpoints, respectively.

To reproduce from the repository root:

```sh
lake exe cache get
python3 scripts/verify.py --jobs 3
```

Fresh output goes to the ignored `validation/` directory. The gate logs above
are release snapshots; source paths inside the dependency reports are relative
to the repository root. Per-module compiler diagnostics are regenerated by the
command and are not duplicated in this release snapshot.

The previous literature and manuscript-alignment review is documented in
[VERIFICATION.md](../docs/VERIFICATION.md); this packaging run did not re-prove
the external literature results or automate natural-language correspondence.
The GitHub Actions workflow was statically checked and invokes this same
verification script; its first hosted run occurs after the repository is pushed.
